# 03 — זרימות שימוש

כל זרימה: צעדים כפי שהם מתועדים או נראים, ומצבי ממשק שמעניינים למימוש. מקור: N = NeatBytes, S = צילום, C = changelog.

## F1 — פתיחה וניווט ראשי (N, S)

1. האפליקציה נפתחת לחלון קבצים (אחד או שניים, לפי כיוון/גודל מסך).
2. סרגל עליון בצורת גלולה: המבורגר (פותח מגירה) + שם המיקום + ספירה (“17 תיקיות, 6 קבצים”) + overflow.
3. מתחת — breadcrumb (“זיכרון פנימי” בכחול = קישור).
4. לחיצה על תיקייה נכנסת; Back עולה רמה; לחיצה ארוכה על Back יוצאת.
5. מהמגירה בוחרים אחסון/מועדף/אוסף — נפתח בחלון הפעיל.

## F2 — שינוי תצוגה ומיון (S — צילום 1)

1. Overflow ← “הגדרות תצוגה”.
2. נפתח popover מעוגן לפינה העליונה (לא דיאלוג מלא, לא bottom sheet) עם 4 אזורים:
   - **מצב תצוגה** — 4 אפשרויות אייקון+תווית, הנבחרת מסומנת בפס מעוגל מתחת.
   - **מצב מיון** — 4 אפשרויות; לנבחרת נוסף חץ כיוון קטן (▼). לחיצה שנייה הופכת כיוון [לא אומת].
   - **זום ברשימה** — סליידר בדיד עם 4 עצירות.
   - **אפשרויות** — “הצג מדורים”, “רק בתיקייה זו”.
3. שינוי חל מייד על הרשימה שמאחור (הרשימה נראית בצד) [נראה, לא אומת].
4. “רק בתיקייה זו” מסומן ← ההגדרה נשמרת לתיקייה בלבד; לא מסומן ← ברירת מחדל גלובלית [פרשנות].

## F3 — בחירה (N)

1. long-press על שורה, או לחיצה על האייקון (רשימה/קומפקטי בלבד) ← מצב בחירה.
2. סרגל הכלים מתחלף לפעולות: Copy, Cut, Delete, Archive, Hide, Share, Select all/inverse, Bookmark (תיקיות), Open with, Shortcut, Rename, Properties.
3. במצב בחירה, long-press על פריט נוסף = בחירת טווח.

## F4 — העתקה/העברה דרך לוח גזירים (N)

1. בחירה ← Copy או Cut.
2. **מצב לוח גזירים**: בסרגל — מספר פריטים, “תיקייה חדשה”, מחוון סוג פעולה (לחיצה = תוכן הלוח).
3. **מצב הדבקה**: ה-FAB הופכים לכפתורי Paste; אפשר לנווט אבל לא לבחור קבצים; כפתור ✓ מבטל.
4. Paste ← ה-FAB הופך למחוון התקדמות.
5. לחיצה על המחוון ← חלון פרטים: מהירות, קובץ נוכחי, זמן שעבר, ETA, תיאור, גרף מהירות. לחיצה על הגרף מכווצת חזרה ל-FAB; חץ מטה סוגר.
6. מ-3.5.x — פעולה שנקטעה ניתנת להמשכה (C).

## F5 — Drag & drop בין חלונות (N, P)

1. בחירת פריטים ← long-press עליהם ← גרירה.
2. ריחוף ~1 שנייה מעל תיקייה פותח אותה (spring-loading).
3. שחרור על תיקייה או על החלון השני ← שאלה: העתקה או העברה. מלווה אנימציה.

## F6 — חיפוש (N)

1. פתיחת חיפוש ← הקלדה (תומך `*` `?` `|` `!`).
2. תוצאות מהאינדקס; בתחתית — הצעה ל-Deep search (אוטומטי אם אין תוצאות).
3. Overflow בזמן חיפוש ← מסנני סוג/גודל/תאריך. אפשר סינון בלי מחרוזת.

## F7 — הוספת חיבור ענן/רשת (N; מסכי האשף לא צולמו)

1. FAB “+” ← תיקייה / קובץ ריק / חיבור ענן/רשת.
2. בחירת פרוטוקול/שירות ← פרטים (שרת, פורט, משתמש, סיסמה / OAuth) [שדות מדויקים לא אומתו].
3. החיבור מצטרף ל“מקומות אחסון” במגירה — עם פנוי/סך הכל כשהשרת מחזיר (כמו NAS בצילום), אחרת פרטי חיבור.
4. מעל 4 אחסונים — מוצגים 3 + מרחיב.

## F8 — שיתוף ברשת מקומית: FTP server / Web share (P, C, N)

1. מגירה ← Toolbox ← FTP Server (בעבר plugin) או Web sharing.
2. FTP: מ-3.6.1 אי אפשר להפעיל בלי משתמש/סיסמה; אנונימי כבוי כברירת מחדל; תיקיית בית ניתנת לשינוי; TLS — Pro.
3. Web: שרת מובנה, פתיחת כתובת בדפדפן במכשיר אחר [ממשק הדפדפן לא אומת].

## F9 — הצפנה (P)

1. בחירת קבצים/תיקייה ← הצפנה (AES-256).
2. פתיחה — סיסמה או טביעת אצבע.
3. באג ידוע ב-3.0 beta: המקלדת מסתירה את שדה הסיסמה של ארכיון/תיקייה מוצפנת (C) — לשים לב ל-IME insets.

## F10 — ניתוח אחסון (S, P, C)

1. Overflow ← **Analyze** (פריט ראשון בתפריט; בממשק עברי עדיין באנגלית).
2. תוצאות: כפילויות, קבצים גדולים, זבל [מבנה המסך לא צולם].
3. בענן — Pro.
4. חלופה בסיסית: מאפיינים ← עמודי תוכן/סוגי קבצים/20 הגדולים (N).

## F11 — ארכיונים (N, P)

1. יצירה: בחירה ← Archive ← פורמט (ZIP/7z) ← סיסמה אופציונלית.
2. חילוץ: פתיחת הארכיון ← חילוץ [האם מנווטים בתוכו כתיקייה — לא אומת].

## F12 — כתיבה במחיצה מערכתית עם root (N)

1. משתמש מבצע כתיבה (rename/move/delete/edit).
2. בדיקת mount point ← אם r/o, remount r/w.
3. ביצוע הפעולה.
4. remount r/o — תמיד, גם בכשלון.
5. פקודות רצות דרך Busybox מצורף (לא עובד בכל מכשיר).

## F13 — שדרוג ל-Pro (S — צילומים 3, 4)

1. מגירה ← כרטיס “BECOME A Pro / Unlock all the Pro features / בלי פרסומות” + פס “Special offer” כתום.
2. מסך Pro: רשימת כרטיסי פיצ'ר (כותרת, תיאור, אייקון צבעוני) ← כרטיס CTA כחול עם כפתור “המשך”.
3. “המשך” ← Google Play Billing [מסך הרכישה והמחיר לא צולמו].

## F14 — סשנים ברקע (N, S)

1. פתיחת מיקום אחר (למשל ענן) בחלון ← המיקום הקודם עובר ל“פועל ברקע” במגירה (בצילום: “הקבצים שלי — /storage/emulated/0”).
2. סשן רקע חדש מחליף את הקודם. לחיצה מחזירה, X סוגר.
