# מקורות הלוחות

עותק של קבצי הקנבס מ-Claude Design (גרסה 17, 13/10/2026). כל `*.dc.html` הוא לוח אחד; `canvas.json` מחזיק את הסדר, המיקומים והכותרות.
הקבצים מפנים ל-`support.js` של סביבת Claude Design, שאינו כאן — הם לא מיועדים להרצה, אלא לקריאת ערכים מדויקים (צבעים, מרווחים, טקסטים).
