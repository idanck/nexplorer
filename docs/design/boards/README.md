# מקורות הלוחות

עותק של קבצי הקנבס מ-Claude Design (גרסה 23, 29/10/2026). `FileIcons.dc.html` (1.10, 30/10/2026) נוצר ישירות בריפו, באותו פורמט. כל `*.dc.html` הוא לוח אחד; `canvas.json` מחזיק את הסדר, המיקומים והכותרות. `Synology.dc.html` (שלב 7, 30/10/2026) — אושר, נוצר ישירות בריפו. `ConnectionStatus-*.dc.html` (1.14, 31/10/2026) — אושרו בקנבס של Claude Design, ועותק שלהם כאן. `Tv-*.dc.html` (1.15, 31/10/2026) — Google TV, אושרו בקנבס; שמות הקבצים והמכשירים בהם — ערכי דוגמה. `Peer-*.dc.html` (1.16, 31/10/2026) — העברה בין מכשירים בטלפון, אושרו באותו קנבס (T5–T6 של הטלוויזיה ב-`Tv-Receive` ו-`Tv-Pair`).
הקבצים מפנים ל-`support.js` של סביבת Claude Design, שאינו כאן — הם לא מיועדים להרצה, אלא לקריאת ערכים מדויקים (צבעים, מרווחים, טקסטים).
לצפייה: הצילומים ב-[`../screens/`](../screens/).
הריפו ציבורי: כתובות, שמות ציוד ושמות משתמש בלוחות הוחלפו בערכי דוגמה (`192.168.1.x`, ‏`pi`, ‏`DiskStation`) — בקנבס המקורי עשויים להופיע ערכים אחרים.
