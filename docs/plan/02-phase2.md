# תוכנית מימוש — שלב 2: כלים על הקבצים המקומיים

> 13/10/2026. ממשיך את [`01-phase1.md`](01-phase1.md). ההחלטות הפתוחות (D2 Shizuku/Root, D3 רשת, D4 ענן, D6, D9, D10) נשארות פתוחות — שום דבר כאן לא תלוי בהן.

## מטרה

מה שחסר כדי שלא יהיה צורך באפליקציה נוספת לעבודה יומיומית על האחסון המקומי: לראות מה תופס מקום, לארוז ולחלץ, לערוך קובץ טקסט, ולשנות שם להרבה קבצים בבת אחת.
הכל בתוך מנגנון ההעברות הקיים (תור, התקדמות, ביטול, שירות חזית) ובלי לדרוס קבצים.

## מה נכנס (שלב 2א — ה-PR הזה)

| תחום | מה | לוח / מקור |
|---|---|---|
| מנתח אחסון | טבעת/פס תפוסה לפי סוג (וידאו, תמונות, אודיו, מסמכים, אפליקציות ומערכת, אחר), "מה אפשר לפנות": כפילויות, קבצים גדולים, זבל ומטמון; תיקיות גדולות. נכנסים מהמגירה (כלים) ומתפריט ⋮ ("מנתח אחסון" — הנפח של התיקייה הנוכחית). בכפילויות העותק הישן בכל קבוצה לא מסומן, ומחיקה בודקת רגע לפני שנשאר עותק שלא השתנה | Analyzer |
| ארכיונים | "הוסף לארכיון" (ZIP, סיסמה אופציונלית — AES-256) מתפריט הבחירה; פתיחת ZIP → "חלץ לכאן" / "חלץ לתיקייה" (שואל סיסמה אם צריך). רץ בתור ההעברות. הגנה מ-zip-slip | Select, SelectList (תפריט ⋮), 03-usage-flows §ארכיונים |
| עורך טקסט | "ערוך כטקסט" לקובץ בודד (עד 1 MB), שמירה אטומית, אזהרה על שינויים שלא נשמרו, קידוד UTF-8; קובץ בינארי או לא-UTF-8 — לא נפתח לעריכה | SelectList (תפריט ⋮), 07-technical-mapping |
| שינוי שם מרובה | כשנבחרו כמה פריטים, "שנה שם" פותח חלון תבנית: החלפת טקסט, קידומת/סיומת, מספור `{n}`, שמירת סיומת; תצוגה מקדימה חיה; התנגשויות מסומנות ולא מבוצעות | 02-features §3 |

## מה בשלב 2ב (PR נפרד)

שני חלונות לטאבלט ולרוחב (לוח Tablet) + גרירה ושחרור + קיצורי מקלדת (F5/F6/Del); מציג תמונות מובנה.

## מה לא (עדיין)

הצפנת קבצים ותיקיות מוצפנות · 7z/RAR · נגני מדיה · שרת FTP/שיתוף ברשת · רשת (D3) · ענן (D4) · Shizuku/Root (D2).

## החלטות מימוש (לא החלטות מוצר)

| נושא | בחירה | למה |
|---|---|---|
| ספריית ZIP | `net.lingala.zip4j:zip4j` (Apache 2.0, Maven Central) | ZIP עם AES-256 ו-ZipCrypto לקריאה; `java.util.zip` לא תומך בהצפנה |
| כפילויות | מעל 64 KB: אותו גודל → אותם 64 KB ראשונים → אותו SHA-256 מלא | hash על כל האחסון לוקח דקות; כל שלב מסנן לפני הבא |
| "אפליקציות ומערכת" | תפוסה כוללת פחות סכום הקבצים שנסרקו | גודל אפליקציות אחרות דורש הרשאת Usage Access — לא מבקשים אותה בשלב הזה |
| עורך | `BasicTextField` על מחרוזת; מעל 1 MB — פתיחה באמצעות אפליקציה אחרת | Solid מגביל ל-2 MB, אבל עורך Compose איטי מעל ~1 MB; עורך קוד חיצוני מגדיל את ה-APK |
| שינוי שם מרובה | ישירות; שם זמני גלוי (`<שם>.nexplorer-rename`) רק להחלפות/שרשרות ולשינוי רישיות | הריגת תהליך באמצע לא מסתירה קבצים |
