# תוכנית מימוש — שלב 3: עוד פורמטים, אפליקציות ומדיה

> 14/10/2026. ממשיך את [`02-phase2.md`](02-phase2.md). ההחלטות הפתוחות (D2 Shizuku/Root, D3 רשת, D4 ענן, D6, D9, D10) נשארות פתוחות — שום דבר כאן לא תלוי בהן.

## מטרה

לפתוח בתוך האפליקציה את מה שעוד שלח החוצה: ארכיונים שאינם ZIP, קבצי APK, ושמע ווידאו.
בלי ספריות נייטיב ובלי הרשאות חדשות רגישות.

## מה נכנס (שלב 3א)

| תחום | מה | לוח / מקור |
|---|---|---|
| ארכיונים | חילוץ 7z (גם מוצפן ב-AES-256, גם כשרשימת הקבצים מוצפנת), TAR, TAR.GZ/TGZ, TAR.BZ2/TBZ2, TAR.XZ/TXZ, וקובץ יחיד ב-GZ/BZ2/XZ. "הוסף לארכיון" — ZIP או 7z, עם סיסמה אופציונלית בשניהם. אותם כללים כמו ב-ZIP: הגנת zip-slip, בלי דריסה, שם זמני ושינוי שם בסוף, ביטול שמנקה, תור ההעברות. קישורים והתקנים בארכיון לא נוצרים (נספרים בהערה) | 02-features §9 |
| APK | הקשה על ‎.apk פותחת גיליון: סמל, שם, חבילה, גרסה, SDK מינימלי ויעד, מספר הרשאות, גודל, טביעת אצבע של החותם; מול המותקן — לא מותקן / חדשה יותר / אותה גרסה / ישנה יותר / מפתח אחר. "התקן" / "עדכן" / "התקן מחדש" מעבירים למתקין של המערכת; "פתח" כשמותקן | 02-features §11 ("מתקין APK") |

## מה נכנס בשלב 3ב

| תחום | מה | לוח / מקור |
|---|---|---|
| נגן שמע | כל קבצי השמע בתיקייה כרשימת השמעה (באותו מיון ובאותו "הצג מוסתרים" כמו בחלון), ניגון ברקע עם התראה ו-MediaSession (מקשי אוזניות, מסך נעילה), סדר אקראי, ניגון חוזר, עטיפה ותגיות. הקשה על ההתראה מחזירה לנגן | 02-features §11 |
| נגן וידאו | מסך מלא, הסתרת הבקרים והסרגל בהקשה, המשך מאותה נקודה אחרי סיבוב (וגם אחרי הריגת תהליך), עצירה ביציאה מהאפליקציה; הסרטונים בתיקייה כרשימה — בסוף סרטון עוצרים | 02-features §11 |

אין לוח עיצוב לנגנים: הם בנויים מהטוקנים הקיימים, ונוספו מידות לבקרים ולעטיפה (`tokens.json` 1.6.0, שפת העיצוב §4 ו-§7).

## מה לא (עדיין)

RAR (אין ספריית Java פתוחה שקוראת RAR5; 7-Zip-JBinding הוא נייטיב ותחת רישיון unRAR) · ‎.apks/.xapk (חבילות מפוצלות — "פתיחה באמצעות") · 7z/ZIP מפוצלים · ZSTD · הצפנת קבצים · שרת FTP · רשת (D3) · ענן (D4) · Shizuku/Root (D2).

## החלטות מימוש (לא החלטות מוצר)

| נושא | בחירה | למה |
|---|---|---|
| ספריות | Apache Commons Compress 1.28 + ‏xz 1.10 (Apache 2.0 / public domain, Maven Central) | 7z עם AES בקריאה ובכתיבה, TAR ו-GZ/BZ2/XZ; Java טהור |
| ממשק אחד | `Archives` — הפורמט לפי השם; ZIP נשאר ב-zip4j. `ExtractTarget` — כללי הכתיבה המשותפים | כל פורמט מקבל אותה הגנה, ובדיקה אחת מכסה את כולם |
| התקדמות בזרמים | בבתים של הקובץ הדחוס שנקראו | ל-TAR.GZ אין אינדקס: הגודל אחרי חילוץ לא ידוע בלי לפענח הכל פעמיים |
| זיכרון | תקרה לפענוח LZMA/XZ — חצי מהזיכרון של האפליקציה; דחיסת 7z ב-preset 3 (מילון 4 MB, ~32 MB) | ארכיון עוין או 7z עם מילון ענק נכשל בהודעה ולא מפיל את האפליקציה |
| סיסמה שגויה ב-7z | שגיאת פענוח (LZMA/CRC) בארכיון מוצפן = "סיסמה שגויה" | 7z לא מאמת את הסיסמה בפתיחה; בארכיון לא מוצפן אותה שגיאה היא קובץ פגום |
| מה מותקן | `<queries>` לאפליקציות עם סמל במסך הבית | בלי ההרשאה הרגישה QUERY_ALL_PACKAGES; חבילה בלי סמל תיראה "לא מותקן" |
| התקנה | `ACTION_VIEW` למתקין של המערכת (לא `PackageInstaller` כמו בעדכון העצמי) | המערכת מטפלת באישור, בהרשאה ובתוצאה; אין סשן לנהל |
| נגנים | Media3 1.5.1 (ExoPlayer, ‏PlayerView, ‏MediaSession; Apache 2.0) | נגן אחד לכל הפורמטים, התראה ומקשים מוכנים; בלי ספריות נייטיב |
| שמע ברקע | `PlaybackService` (‏MediaSessionService, לא מיוצא) + MediaController ב-`AudioPlayerViewModel` | הניגון לא תלוי במסך; הרשימה נקראת מהשירות, ולכן חזרה מההתראה מראה אותה רשימה. רק האפליקציה מוסיפה פריטים — שלט חיצוני לא מבקש נתיב משלו |
| וידאו | ExoPlayer מקומי ב-ViewModel, לא בשירות | סיבוב מסך לא מפסיק; וידאו בלי מסך לא נחוץ. לוקח את מיקוד השמע — המוזיקה נעצרת |
| מה נפתח בפנים | `MediaFormats`: mp3, m4a, aac, flac, wav, ogg, opus, amr; ‏mp4, m4v, mkv, webm, mov, 3gp, ts, avi, flv | מה ש-ExoPlayer מפענח בלי הרחבות; WMA, ‏WMV ו-MIDI ממשיכים לאפליקציה אחרת |
| כיוון | ציר הזמן והבקרים משמאל לימין גם בממשק עברי | מוסכמה של נגנים (Material: בקרי מדיה לא משתקפים) |
